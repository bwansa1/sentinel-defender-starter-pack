# Deployment Guide

## Requirements

- Microsoft Sentinel
- Log Analytics Workspace
- Microsoft Defender

## Deploying Detection Rules

1. Open Microsoft Sentinel.
2. Navigate to Analytics.
3. Select Create Rule.
4. Copy KQL query.
5. Configure alert logic.
6. Enable rule.

## Deploying Hunting Queries

1. Open Logs.
2. Paste KQL query.
3. Execute search.
4. Save query if desired.

## Validation

- Verify logs are being ingested.
- Verify alerts trigger correctly.
- Review false positives.
